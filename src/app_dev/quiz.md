# Python 問題集

## 上級問題

### 1:クラスとデコレーター
**問題**
以下の要件を満たす、デコレーター`@log_execution_time`を作成せよ。
- 関数の実行時間を計測し、関数名と実行時間をログとして出力する。
- クラスメソッドにも適用できるようにする。
- ログはloggingモジュールを利用してINFOレベルで出力する。
さらに、以下のようなクラス`DataProcessor`にこのデコレーターを適用する。

### 2:非同期処理(asyncio)
**問題**
以下の要件を満たす、複数のAPIからデータを取得する非同期関数`fetch_all_data`を作成せよ。
- fetch_data(url:str)という非同期関数を利用して、複数のURLから並列にデータを取得する。
- タイムアウト(例：5秒)を設定し、タイムアウトした場合にはログに警告を書き出す。
- 結果は辞書形式で返す。(キー：URL、値：レスポンス or None)

### 3:メタクラス
**問題**
以下の要件を満たす、すべてのクラスに自動的に`__str__`メソッドを追加するメタクラス`AutoStrMeta`を作成せよ。
- `__str__`はクラスの属性とその値を`ClassName(attr1=value1, attr2=value2)`の形式で返す。
- このメタクラスを使って`User(name = "John", age=35)`のようなクラスを定義し、str(usr)の出力を確認せよ。

### 4:データエンジニアリング・ETLパイプライン設計
**問題**
以下の要件を満たす、`ETLPipeline`クラスを設計してください。
- `extract()`:CSVファイルからデータを読み込む(pandas使用)
- `transform()`:特定の列の欠損値を中央値で補完し、日付列をdatetime型に変換する
- `load()`:整形したデータをSQLiteに保存する

### 5:アルゴリズム・パズル系
**問題**
与えられた文字列の中で、最長の回文部分文字列を返す関数`longest_palindrome(s:str) -> str`を実装せよ。
- 時間計算量はO(n^2)に抑える
- "babad" → "bab" or "aba"


## 中級問題

### 1:クラス設計と特殊メソッド
**問題**
以下の要件を満たす`Book`クラスを作成せよ。
- 属性：title, author, price
- `__str__`メソッドで"『タイトル』 by 著者 - ￥価格"の形式で出力
- `__eq__`メソッドで、タイトルと著者が同じなら同一とみなす
- `discount(rate:float)`メソッドで価格を割引する(例：rate=0.1 → 10%割引)

### 2:ファイル操作と例外処理
**問題**
CSVファイル`data.csv`を読み込み、各行の合計値を計算して新しいファイル`summary.csv`に書き出す関数`summarize_csv()`を作成せよ。
- 数値以外の値が含まれていた場合はその行をスキップし、ログに警告を出す
- ファイルが存在しない場合は例外処理で対応する

### 3:辞書とリストの操作
**問題**
以下のようなデータ構造を受け取り、各ユーザーの平均スコアを計算する関数`calculate_averages(data:dict[str,list[int]]) -> dict[str,float]`を作成せよ。
```Python
    data = {
        "John" : [789,45,7],
        "Bob" : [7897,222],
        "Alice" : [111,777,474,545.456]
    }
```

### 4:関数の引数の使い方
**問題**
可変長引数を利用して、任意の数の数値を受け取り、最大値・最小値・平均値を返す関数`analyze_numbers(*args: float) -> dict[str,float]`を作成せよ。

### 5.簡単なデータ分析(pandas)
**問題**
以下のようなCSVファイルを読み込み、月ごとの売り上げを計算する関数`monthly_sales_summary()`を作成せよ。

2025/10/4,78521
